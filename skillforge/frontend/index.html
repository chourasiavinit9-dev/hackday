OPEN SOURCE · AGENT SKILL

Install SkillForge on your CLI

SkillForge is packaged as an open-source Agent Skill compatible with the Antigravity (AGY) CLI. Anyone can install it in one command and run it as a first-class skill.

⚡ Install via AGY CLI Recommended
agy skill install https://github.com/chourasiavinit9-dev/hackday
Requires the Antigravity CLI — installs SkillForge as a persistent skill on your workspace.
🐍 Clone & run locally
git clone https://github.com/chourasiavinit9-dev/hackday && cd hackday/skillforge/backend && pip install -r requirements.txt && python main.py
Needs Python 3.11+ and a GEMINI_API_KEY in your .env
